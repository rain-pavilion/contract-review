# 合同审查人工批注/审查样本来源与爬取记录

日期：2026-11-19（数据抓取时间：2026-11-18 夜间至 11-19）
定位：为 P1“独立人工标注目标测试集”做**外部参考样本**摸底与抓取。本文档记录已抓到的权威人工审查文本、访问受限的来源、以及为什么这些样本**不能**直接充当本项目金标。

## 一句话结论

已从权威官网实际抓取两类可用外部样本：**全国合同示范文本库的“合同全文 + 发布机关风险提示”**（部委文本 113 份全部完成，共 880 条人工审查提示、约 101 万字符合同原文）与**市场监管／法院官方案例中的人工法律分析**（6 个来源、43,318 字符、可切分 62 个案例段）。另确认人民法院案例库、裁判文书网、国家基础学科数据中心等需要登录或无法匿名抓取，未绕过。以上均为**外部人工审查指引/案例级分析**，不是逐条款独立标注，也不是本项目金标。

## 一、已抓取数据

### 1.1 全国合同示范文本库（市场监管总局）

- 站点：`https://htsfwb.samr.gov.cn/`（国家市场监督管理总局合同示范文本库，官方说明“面向社会公众免费查阅下载”）。
- 样本形态：每个示范文本页面 = **完整合同文本** + 右侧**“风险提示”**（发布机关撰写，按“合同价款条款／格式条款风险／违约责任设置／争议解决／签章”等主题给出审查指引）。这是目前找到的最接近“合同 + 人工审查批注”的官方公开语料。
- 抓取结果（部委文本，`loc=false`）：113/113 份成功，0 失败；880 条风险提示；合同正文合计 1,010,225 字符；风险提示中位数 8 条/份（最多 15 条），97 份 ≥5 条，4 份无风险提示。
- 地方文本（`loc=true`）：489/489 份成功，0 失败；已完成并合并进同一索引。全库合计 **602 份文本、3,466 条风险提示、约 399 万字符合同正文**；风险提示中位数 6 条/份，595 份至少 1 条，7 份无风险提示；21 条提示只有主题无正文；8 份短文本（<500 字符）混入目录，下游使用前需过滤。
- 全库统计：`data/annotation_samples/htsfwb/summary.json`（按部委/地方、提示条数、字符数、空提示、短文本统计）。
- 数据字段：`doc`（标题/发布机关/年份/编号/地区/类型）、`contract_text`、`human_annotations[{kind:"official_risk_tip", topic, content}]`、`source`（URL/抓取时间/字节数/SHA-256）。
- 保存位置：`data/annotation_samples/htsfwb/`（`contracts/<id>.json`、`index.jsonl`、`manifest.json`）；未保存原始 HTML（单页约 1MB，多为内嵌图片），以响应 SHA-256 与字节数留证，可随时按 URL 复抓比对。
- 入口脚本：`tools/crawl_htsfwb_annotations.py`，命令：

```powershell
.\.venv\Scripts\python.exe tools\crawl_htsfwb_annotations.py --scope national --delay 0.9 --out data\annotation_samples\htsfwb
.\.venv\Scripts\python.exe tools\crawl_htsfwb_annotations.py --scope local --delay 0.9 --out data\annotation_samples\htsfwb
```

## 四、为什么这些样本不能直接作为本项目金标

1. **标注对象不同**：风险提示是“发布机关对示范文本的通用审查指引”，不是对某一份真实合同逐条款判断；官方案例是争议发生后的裁判/处罚分析，不是事前审查标签。
2. **标注口径不同**：没有本项目风险码、实体边界、法条引用 relevance 的定义；直接当标签会引入口径漂移。
3. **独立性与训练暴露未知**：这些材料是否已进入本项目的训练/调参语料未清查；不能同时当训练数据与独立测试金标。
4. **许可与再分发**：政府网站文本版权归发布机关；公开可查阅不等于可批量再分发或商用。当前仅保存抓取结果用于内部研究与验收准备，未承诺对外分发。
5. **案例级 ≠ 条款级**：法院裁判要旨可以说明某类条款无效，但不能自动生成某份合同某条款的风险标签与 offset。

因此，本记录只完成“外部参考样本摸底与可复现抓取”，**不改变**“独立人工标注目标测试集尚未建立”的结论。
