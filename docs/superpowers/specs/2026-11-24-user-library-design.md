# 独立用户库与公开注册

用户要求新增管理账号的库和注册页面，继续保留已授权的用户/管理员权限规则。

第三个业务库为 `data/libraries/users.sqlite`，集中保存账号、PBKDF2 口令哈希、可撤销会话与账号审计。合同库只保留用户编号外键索引；实时授权从附加的用户库读取，避免禁用、角色变更与业务写入之间的授权竞态。现有 ContractLibrary 账号方法委托 UserLibrary，保持引擎、API、CLI 的兼容。

首次启动从旧合同库迁移账号和会话，保留 user_id、口令哈希、角色与现有归属。先将账号安全提交到独立库，再在合同库事务中移除凭据及会话表，改为只有 user_id 的外键索引；重复启动不能覆盖新口令或重建已撤销的会话。生产操作前停服务并做本机备份。迁移失败不删除旧账号来源，不改原历史来源数据库。

公开注册通过用户名、密码和确认密码完成，不要求邮箱/手机。新账号固定为启用的普通用户，无权自选角色、归属或管理员权限。注册仅在管理员已初始化且服务端允许时开放；注册成功返回登录页，不自动建立会话。用户名重复不覆盖已有账号，密码至少12位，用户名2–64位允许中文、字母、数字、下划线、点和短横线。管理员仍能创建、停用、重置口令和调整角色。

HTTP：GET /api/auth/status 添加 registration_enabled；POST /api/auth/register 接受 username/password/password_confirm，成功201返回 registered/username/message，不返回密码或会话。拒绝跨站、无效表单及权限字段；独立有界注册限流。环境配置 ZLQL_USER_LIBRARY_PATH 和 ZLQL_PUBLIC_REGISTRATION（默认开启）。未初始化时不能抢注管理员。

前端在原登录面板增加“注册账号/返回登录”，沿用现有样式与响应式布局；表单、口令及提示在切换账号或退出时清理，成功保留用户名用于登录。管理员用户管理页沿用现有入口，数据来自独立用户库。

验证：独立库中账号和会话分离、幂等迁移/碰撞保护、原账号/合同归属和会话撤销、公开注册最小权限/重名/弱口令/确认错误/限流/跨站、注册到登录到上传、管理员管理注册用户、桌面及移动端表单与账号切换。
