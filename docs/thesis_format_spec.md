# 南通大学计算机学院本科毕业设计论文 · 格式规范（实测版）

> 数据来源：`计科4班彭雅玲_conv.docx`（由老式 `.doc` 转换而来，正文 309 段 + 14 张表，
> 约 2.1 万字符，4 个 section）。本文所有数值都是**从该样本的 `styles.xml` /
> `document.xml` / `numbering.xml` 里逐项读出来**的，不是按经验猜的。
> 配套文件：`tools/thesis_styles.json`（机器可读样式清单）、
> `tools/thesis_builder.py`（生成器）、`docs/thesis_demo.docx`（演示产物）。

单位换算备忘：`1 twip = 1/20 pt = 1/1440 inch`；`1 cm ≈ 567 twips ≈ 28.35 pt`。

- 西文/`ascii`/`hAnsi`/`cs`：**Times New Roman**

## 4. 封面

结构（自上而下，全部用 `Normal` 样式 + 直接格式）：

1. 空段（1.5 倍行距，撑开顶部空白）
2. **「毕业论文」**：居中，**21 pt**（`sz=42`），不加粗，`kern=2`
3. 空段（`sz=56` 空 run，撑高度）
4. **题目表**：2 行 × 2 列，无边框（`Normal Table`），列宽 2314 / 6065 twips（合计 14.78 cm）；
   label「论文题目：」右对齐 **22 pt 加粗**，题目内容 22 pt 加粗两端对齐；长题目按两行、标签重复
5. 4 空格间隔段（`sz=28`，带下划线）
6. **信息表**：3 行 × 4 列，无边框，列宽 1659 / 2456 / 1565 / 2457 twips（2.93 / 4.33 / 2.76 / 4.33 cm）；
   单元格 **14 pt**，label 加粗右对齐、值居中；标签用全角空格对齐：
   `学生姓名：` `学　　号：` `专　　业：` `指导老师：` `参考文献：` `论文字数：`
7. 日期段：居中，**14 pt**，首行缩进 560 twips
8. 分页 → 目录页

要点：两张表都是 `tblW=dxa` + `jc=center` + `tblInd=0` + **无边框**；信息表在样本里还带
`tblpPr`（浮动定位），生成器改用等价的居中固定列宽表，视觉一致且不会随 Word 版本漂移。

## 5. 摘要 / Abstract / 关键词

| 元素 | 实测格式 |
|---|---|
| 「摘要」标题 | **不用** `论文1级标题`：`Normal` + 黑体加粗 12 pt、居中、段前/段后 326 twips（16.3 pt）、单倍行距、首行缩进 0、`outlineLvl=0`（仍能进目录 1 级） |

| 英文摘要正文 | `论文正文` 样式（英文自动走 Times New Roman） |
| Keywords 行 | 标签 `Keywords:` 加粗，内容 10.5 pt，词间用**半角分号加空格「; 」** |

## 6. 目录

| 项目 | 实测值 |
|---|---|
| 标题「目录」 | `目录标题格式`：黑体 **16 pt** 粗、居中、单倍行距、段前与段后各 326 twips（16.3 pt）、**段前分页** |
| 目录域 | `TOC \o "1-3" \h \z \u`（1~3 级、超链接、使用大纲级别），含 `hyperlink` + `PAGEREF` + 页码占位 I / II / 1 |
| 条目样式 | `toc 1` / `toc 2` / `toc 3` |
| 条目字号 | **11 pt**（段落直接 `sz=22`），`kern=2` |
| 条目缩进 | 1 级 **0**；2 级 **480 twips = 0.85 cm**；3 级 **960 twips = 1.69 cm** |
| 制表位 | 右对齐 + **点状前导符**，位置 **8290 twips = 14.62 cm**（= 版心宽度） |
| 行距 | 1.5 倍，段前段后 0 |
| 页码前缀 | 摘要 I、Abstract II、第1章 1 |

**兜底策略**：TOC 是域，部分机器打开时不会自动刷新。生成器同时写入一份**静态目录**
（用 `toc 1/2/3` 样式 + 制表位 + 页码占位），即使域不更新也能看到完整层级；在 Word 里
`Ctrl+A` → `F9` 可刷新成真实页码。

样本目录实际覆盖：摘要、Abstract、6 章（共 8 个 `toc 1` 之外的层级）、结论、参考文献、致谢、附录，
2 级条目 20 余条、3 级条目 15 条左右 —— 全书约 3 页目录。

## 7. 图、表与题注

### 7.1 编号规则

- 形式：**`图<章号>-<序号>` / `表<章号>-<序号>`**，例如 `图3-1`、`表4-1`、`表6-2`；
  序号**每章重新从 1 开始**，与章号用半角连字符。
- 题注文字与编号之间 **一个半角空格**：`表4-1 养殖信息表`、`图3-1 企业员工用例图`。
- 正文引用写「如图3-1所示」「见表4-1」，编号必须与题注一致。

### 7.2 题注样式（`Caption`）

| 属性 | 值 |
|---|---|
| 字体 | 中文 **黑体**；字号 **10.5 pt**（五号） |
| 对齐 | 居中 |
| 行距 | 样式继承 1.25 倍；样本段落上直接改成 **1.5 倍** |
| 首行缩进 | 样式自带 `firstLine=420`（0.74 cm），**段落上必须清零**（`firstLine=0`） |
| 位置 | **表题在表上方**（与表 `keepNext` 同页）；**图题在图下方** |
| 加粗 | 文字未加粗（样本只有段落标记 `rPr/b`，正文 run 无 `b`） |

### 7.3 表格

- 样本数据表是三线表：`tblBorders` 只有 `top`、`bottom` 各 `single sz=12`（**1.5 pt**），
  无 `insideH`/`insideV`/左右边线；表头行下边再加 `sz=6`（0.75 pt）细线。
- 单元格：**10.5 pt**，水平居中，`firstLine=0`，单倍行距，表头不加粗，`trPr/jc=center`。
- 表宽取版心 14.64 cm 内，跨页长表需人工加「重复标题行」。

### 7.4 插图

- 图片段落居中、无首行缩进、单倍行距，宽度不超过版心 **14.64 cm**。
- 缺图时留占位段（灰字 `【此处插入图 x-x】`），保证正文引用与图题编号不断链。

## 8. 参考文献（顺序编码制，GB/T 7714—2015）

| 项目 | 实测 |
|---|---|
| 标题 | 「参考文献」，一级标题位置；样本用 `Normal`+黑体粗体居中（`outlineLvl=0`），页首用 run 内分页符；生成器统一走 `论文1级标题` |
| 编号 | `[1] [2] [3] …` 顺序编码，方括号为**半角**；由 `numId=5` 的列表（`lvlText="[%1]"`）或字面文本生成 |
| 版式 | 悬挂缩进：`left_indent = 480 twips`、`first_line_indent = -480 twips`（回行对齐到正文缩进位置） |
| 字号 | 12 pt，与正文一致；行距 1.5 倍 |
| 数量 | 样本 **17 条**（中文 13 + 英文 2 + 学位论文 4 类混合）；封面「参考文献：__」栏需与条数一致 |

可直接照抄的条目示例（样本原文）：

```
[1] 本刊编辑部.日本核污水排放毒害海洋祸及全球[J].防灾博览,2023,(05):42-43.
[2] 胡慧茵.福岛核污染水排海至少持续30年多国限制进口日本水产品[N].21世纪经济报道,2023-08-25(001).DOI:10.28723/n.cnki.nsjbd.2023.003388.
[5] 杨仪,赵于娴,徐钰菲,等.水产品中孔雀石绿快速检测方法研究进展[J].中国食品添加剂,2025,36(01):144-151.
[8] 李梦琪.基于区块链的水产品供应链追溯系统设计与实现[D].上海海洋大学,2021.DOI:10.27314/d.cnki.gsscu.2021.000618.
[12] Pei Yin,Jing Cheng. A MySQL-Based Software System of Urban Land Planning Database of Shanghai in China[J]. Computer Modeling in Engineering & Sciences,2022,135(3).
```

格式要点（照样本归纳）：

- 期刊：`作者.题名[J].刊名,年,卷(期):起止页.` —— 作者 3 人以上用「,等.」，英文用「,et al.」
- 学位论文：`作者.题名[D].学校,年份.DOI:…`
- 报纸：`作者.题名[N].报纸名,出版日期(版次).DOI:…`
- 中文文献用**半角逗号+半角句点**，条目末尾有句点；不要加空格美化。

## 10. 必须人工填 / 必须人工核的清单

**封面（生成器只放占位符 `【待填】`）**

1. 论文题目（中文，≤ 25 字，过长按两行断句）
2. 学生姓名
3. 学号
4. 指导老师（含职称，如「李四 副教授」）
5. 专业（样本：计算机科学与技术）
6. 参考文献条数（必须等于正文实际条数）
7. 论文字数（必须等于 Word 统计值）
8. 日期（样本格式：`2025年5月18日`，无前导零）

**正文**

9. 目录页码：打开后 `Ctrl+A` → `F9` 更新域（或右键「更新域」→ 只更新页码）
10. 所有 `【此处插入图 x-x】` 占位段 → 替换为真实截图，并保留图下题注
11. 公式：`equation_like()` 只是居中占位，需用公式编辑器（或 LaTeX 转 OMML）替换
12. 参考文献角标：正文 `[n]` 需设为上标（样本是 REF 域）
13. 表格跨页时手动勾选「重复标题行」；宽表必要时改横向节
14. 图表编号与正文引用逐处核对（生成器按章自动编号，人工改章序后要重新生成）
15. 页眉（学校若要求「南通大学本科毕业设计（论文）」）需手动填；样本页眉为空
16. 附录里的代码清单：`code_block()` 用 Consolas 9 pt + 浅灰底纹，正式提交前确认字号符合学院要求

## 11. 生成器用法（`tools/thesis_builder.py`）

```python
from thesis_builder import ThesisBuilder, DEFAULT_TEMPLATE

b = ThesisBuilder(DEFAULT_TEMPLATE, "out.docx")   # 以样本为模板，样式/页面 100% 继承
b.cover(title="…", student="…", advisor="…", student_id="…",
        ref_count="17", major="计算机科学与技术", word_count="21000",
        date="2025年5月18日")
b.toc_field()                       # TOC 域 + 静态目录（save() 时按实际标题补全）
b.abstract_cn("…", ["水产品", "追溯系统", "Spring Boot", "Vue"])
b.abstract_en("…", ["Aquatic Products", "Traceability System", "Spring Boot", "Vue"])

b.table(["列1", "列2"], [["a", "b"]], caption="表4-1 示例表", three_line=True)
b.figure(None, caption="图3-1 系统总体结构图")     # 缺图自动占位
b.refs(["作者.题名[J].刊名,2023,(05):42-43.", "…"])

report = b.save()                   # 回读校验：段落数/样式统计/TOC 域/页边距
```
